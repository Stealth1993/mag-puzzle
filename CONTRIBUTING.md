# Contributing Guidelines 🧩

Thank you for your interest in contributing to the **Magazine Puzzle Repository**!  
We welcome new puzzles, improvements, and creative ideas. Please follow these guidelines to ensure smooth collaboration.

---

## 📌 How to Contribute
- **Fork the repository** and create a new branch for your changes.
- **Add or update puzzles** in `puzzle.json`.  
  - Each puzzle entry should include:
    - `title`
    - `author`
    - `difficulty` (Easy, Medium, Hard)
    - `date`
    - `content` (clues, grid, or puzzle data)
    - `solution`
- **Update `index.html`** if you add new puzzle categories or sections.
- **Modify `script.js`** only if you are improving puzzle logic or interactivity.
- **Edit `style.js`** only for layout, theme, or visual improvements.

---

## 📝 Puzzle Format
- All puzzles must be stored in `puzzle.json` using valid JSON.
